- **Театры** - нет датасетов  
- **Культурные центры** - нет датасетов
- **Кино** - нет датасетов

### 2. Общественное питание
- **Рестораны** - нет публичных датасетов с координатами
- **Кафе** - нет датасетов
- **Бары** - нет датасетов

### 3. Природа и отдых
- **Национальные парки** - нет географических данных (только названия)
- **Заповедники** - нет координат

### 4. Здравоохранение  
- **Больницы** - есть списки БЕЗ координат
- **Клиники** - нет публичных данных
- **Аптеки** - только локальные (Беэр-Шева, Хайфа)

### 5. Госучреждения
- **Мэрии** - нет централизованного датасета
- **Министерства** - нет публичных координат
- **Почта** - есть списки БЕЗ координат

## 🔍 Почему данных нет?

### Проблема 1: Отсутствие централизации
- Каждый муниципалитет публикует свои данные отдельно
- Нет национального реестра POI
- Минкультуры, Минприроды не публикуют геоданные

### Проблема 2: Privacy & Security
- Рестораны/бизнесы - коммерческие данные (Google, Waze)
- Больницы - чувствительные объекты (публикуются без точных координат)
- Госучреждения - безопасность

### Проблема 3: Технические
- Многие датасеты - только адреса (нужен geocoding)
- Старые форматы данных (XLS без координат)
- Данные обновляются редко

## 🛠️ Возможные решения

### Краткосрочные
1. ✅ **Использовать муниципальные порталы**
   - Jerusalem: datacity.org.il
   - Tel Aviv: opendata.tel-aviv.gov.il
   - Haifa: haifa.muni.il/opendata

2. **Geocoding существующих данных**
   - Использовать Nominatim/GovMap API
   - Преобразовать адреса → координаты
   - Кэшировать результаты

### Долгосрочные  
1. **API интеграции**
   - Ministry of Culture API (если существует)
   - Nature & Parks Authority
   - Ministry of Tourism

2. **Краудсорсинг**
   - OpenStreetMap Israel данные
   - Wikidata coordinates
